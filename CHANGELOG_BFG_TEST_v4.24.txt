CHANGELOG BFG TEST v4.47
Date : 2026-08-04
Base : TEST v4.46 sélection NOTAMs verte et rouge

Modifications :
- METAR / TAF : délai du service worker porté de 5 secondes à 25 secondes pour les appels au proxy CheckWX.
- METAR / TAF : ajout d’une seconde tentative automatique en cas d’interruption, d’AbortError ou d’erreur temporaire HTTP 502/503/504.
- METAR / TAF : limitation à 4 requêtes CheckWX simultanées afin d’éviter une rafale trop importante lors du chargement de plusieurs aérodromes.
- METAR / TAF : une panne sur un METAR ne fait plus échouer le TAF du même terrain, et inversement.
- METAR / TAF : la dernière donnée déjà affichée reste visible si une actualisation échoue.
- METAR / TAF : mise en cache stable par couple type/OACI pour permettre une reprise locale en cas de réseau dégradé.
- Message d’erreur réseau rendu plus précis lorsque les deux tentatives échouent.

Fichiers modifiés :
- index.html
- manifest.json
- sw.js
