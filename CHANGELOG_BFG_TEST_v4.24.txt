CHANGELOG BFG TEST v4.52
Date : 2026-08-11
Base : TEST v4.51 chargement météo équilibré

Objectif :
- Conserver automatiquement les METAR/TAF déjà chargés pour les réafficher à la prochaine ouverture de la PWA.
- Inclure ces METAR/TAF dans le briefing partagé.
- À la restauration locale ou à l'ouverture d'un partage, afficher les données sauvegardées sans lancer de nouvelle requête CheckWX.

Modifications :
- Ajout d'un collecteur central collectWeatherDataSnapshot_() pour les aérodromes dont la météo est chargée.
- Après chargement/rafraîchissement METAR/TAF réussi, sauvegarde locale automatique différée et regroupée via le mécanisme de snapshot existant.
- La sauvegarde locale currentSession contient désormais réellement weatherData (la v4.51 testait window.collectWeatherData sans que cette fonction soit définie).
- Réaffichage de weatherData au démarrage depuis IndexedDB, sans appel réseau météo.
- Le partage portable reprend directement le snapshot METAR/TAF affiché au moment du clic sur Partager, sans requête de rafraîchissement.
- À l'ouverture d'un briefing partagé, restauration directe du snapshot METAR/TAF reçu, sans appel CheckWX.
- Mutualisation de la logique de restauration locale et partagée.
- Conservation d'un horodatage savedAt par aérodrome dans le snapshot, sans modifier l'affichage opérationnel existant.
- Comportement de chargement v4.51 conservé : 8 requêtes simultanées, délai 15 s, retry en fin de file.

Fichiers modifiés :
- index.html
- manifest.json
- sw.js

Fichier NAS :
- Aucun fichier NAS à remplacer.

Tests recommandés :
1. Ouvrir le BFG TEST v4.52 et cliquer sur Charger Météo.
2. Attendre la fin du chargement puis fermer complètement la PWA.
3. Rouvrir la PWA : les METAR/TAF précédemment chargés doivent être visibles sans cliquer sur Charger Météo.
4. Créer un partage après chargement météo.
5. Ouvrir le code de partage sur un autre appareil : les METAR/TAF doivent apparaître immédiatement avec le briefing, sans lancement d'une requête météo.
6. Vérifier que le bouton Charger Météo reste disponible pour une actualisation volontaire ultérieure.
